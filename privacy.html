Privacy policy

Last updated 20 October 2026

post-doc-hunt is a personal tool used only by its developer and owner, Aamir Malik. It is not distributed to or used by any other person.

Data accessed

The application uses the Gmail API with the owner's explicit consent to create draft messages in the owner's own Gmail account and to read messages the owner has sent. It accesses no other user's data.

Data storage and sharing

Data obtained through Google APIs is stored only on devices controlled by the owner and is never sold, shared with third parties, or used for advertising. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the owner's Google Account permissions page.
